Method: built-in `image_gen`.

Purpose: a playful illustration of six specialized robots collaborating on one Issue.

## Generation Prompt

Use case: illustration-story.
Create a delightful, highly polished editorial illustration for the RepoAgent GitHub project: "把一个 Issue，交给一支各司其职的修复小队。"
A warm, witty little robot software-repair workshop, not a flowchart. Panoramic landscape illustration about 2:1, high resolution, carefully composed with comfortable margins and airy white background. Charming tactile miniature diorama / handcrafted designer-toy aesthetic, rounded ivory and silver robots, clear physical expressions, tiny useful tools, sophisticated rather than childish. Palette: fresh teal and emerald, sunny yellow, tomato-coral accents, charcoal outlines, cool light grays. Bright and clean. Avoid dominant purple, beige/tan, dark navy backgrounds, atmospheric blur, decorative orbs, gradients, weapons, animals and generic stock imagery.

Scene: an oversized incoming issue ticket arrives on the left, labelled exactly "ISSUE", with a red broken code bracket symbol on it. A coordinated team of SIX distinct, friendly little robots collaboratively transforms it into a neatly repaired code tile and passing checkmark at the right.
The collaboration must be visible through shared objects, handoffs, pointing, and physical teamwork, not six disconnected portraits:
1) a curious memory-search robot on the left climbs a tiny ladder at an organized archive of glowing turquoise knowledge cards; it hands one relevant card to the coordinator.
2) the coordinator robot at center stands by a small transparent task board, pointing to a simple plan with little code-file shapes and assigning work.
3) a coding robot at a tiny keyboard builds the code tile, focused yet cheerful.
4) an analytical failure-review robot in orange safety glasses examines a small red failed-test slip with a magnifying glass and points out the specific cracked bracket to its teammate.
5) a corrective coding robot uses a precision tool to replace the cracked bracket on the SAME shared code tile, assisted by the first coding robot.
6) an experience-curator robot at far right stamps a successful repair card and carefully files it into two neat little archives. One archive has a globe pictogram, the other a folder/repository pictogram. This robot smiles proudly.
A small automated testing gate/workbench shows a prominent fresh green checkmark for the repaired code; this testing station is a machine, not an extra robot character.
Use a subtle mint-colored path or workbench conveyor to unify the activities. Add tasteful tiny comedic details: a robot standing on a stack of books to reach the plan board, a miniature coffee mug, neatly collected spare brackets, a teammate holding a work light. Keep the core scene uncluttered and each action instantly readable.

Text: put the exact Chinese headline across the clean upper area, beautiful large legible typography:
"把一个 Issue，交给一支各司其职的修复小队。"
Small brand signature "RepoAgent" below or upper left, with no extra slogans.
Beyond the headline, "RepoAgent", and the ticket "ISSUE", use pictograms rather than words. No other labels, no speech bubbles, no watermarks, no benchmark numbers.
Make it feel like an imaginative team genuinely collaborating to fix one software problem, not isolated robot mascots and not a corporate architecture diagram.
